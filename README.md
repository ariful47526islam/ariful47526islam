## About Me

I design and ship AI-native web systems: autonomous agents, edge-first backends, and open-source tooling under **ABsUP** and the **OpenCodeWEB** organization.

Recent public work spans a polyglot AI agent (`AG`), a self-sovereign AI OS (`OS`), a master intelligence engine (`AiA`), Cloudflare Worker gateways, and a family of Pages-hosted product surfaces (`GDBx`, `GDMx`, `DSGx`).

- Open-source builder focused on **AI agents**, **edge infrastructure**, and **web platforms**
- Active across TypeScript, JavaScript, HTML, and Python
- Shipping on Cloudflare Workers / Pages, with MCP and A2A protocol experiments
- Open to collaboration on agent tooling, serverless queues, and hybrid UI infrastructure
